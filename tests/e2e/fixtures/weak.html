Weak-header fixture page

Served over HTTPS, so the connection signals pass, but every response-hardening header is present and bad: unsafe-inline and unsafe-eval in the CSP, X-Frame-Options: ALLOWALL, Referrer-Policy: unsafe-url, Permissions-Policy: geolocation=* and HSTS: max-age=0 (which actively switches HSTS off).

The point of this fixture is that "present" is not the same as "good": a page like this must not be scored as if the headers were missing, and must not be scored as if they were fine.
