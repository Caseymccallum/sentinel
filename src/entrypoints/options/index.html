Sentinel settings

Sentinel scores the page you are on and explains every point it deducts. Everything is analysed locally — no account, no telemetry, no network requests.

Modules

Each module can be switched off on its own. A switched-off module is a gap in the report, never a bonus: its checks report “could not be checked” and its weight is redistributed across the modules that did measure.

    Your data

    The Change Monitor keeps per-site security history — scores, host names and change digests, never page paths, queries or titles — in this browser only, capped at 500 sites. Forgetting is a user action, like deleting cookies.

      Scores live in session storage and disappear when the browser closes. Module settings and site history live in this browser's local storage and never leave it.
